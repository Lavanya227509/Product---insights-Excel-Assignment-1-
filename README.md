# 📊 Product Data Exploration & Analysis Using Excel

## 📌 Project Overview

This project is part of my Data Analytics learning journey, where I am building my portfolio and developing practical skills in Microsoft Excel.

The objective of this project is to perform basic data exploration and analysis on a Product Dataset using Excel formulas and functions.

The analysis focuses on data summarization, conditional logic, and text manipulation techniques that are commonly used in data analysis.

## 🎯 Objectives

- Explore and summarize product data
- Calculate total, average, minimum, and maximum prices
- Categorize products based on price
- Perform conditional calculations using SUMIF and COUNTIF
- Extract information from Product IDs using text functions
- Practice fundamental Excel data analysis techniques

## 📂 Dataset

The dataset contains information about different products.

### Dataset Attributes

- Product ID
- Product Name
- Brand Name
- Quantity
- Category
- Price
